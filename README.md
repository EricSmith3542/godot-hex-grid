# godot-hex-grid
This repository contains the work that I have done while following the catlikecoding Hex Map tutorial found here:
https://catlikecoding.com/unity/tutorials/hex-map/

The tutorial was made for Unity, and I am following along in Godot in order to provide more of a learning opprotunity beyond just following a tutorial. I got this idea from the following reddit post from someone who did something similar: https://www.reddit.com/r/godot/comments/1hq3liv/implemented_3d_hexagonal_grid_maps_in_godot_based/

I do not plan on using their work to guide mine in order to challenge myself to bridge the gaps between the Unity tutorial and the Godot implementation.
